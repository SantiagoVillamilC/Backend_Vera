# Dependencias de la variante opcional de Kokoro en GPU (VERA_VOZ_DISPOSITIVO=cuda en servidor.py).
# No las usa ninguna imagen ni ningún workflow: la imagen CPU sigue con requirements.txt.
#
# Instalar en un venv de Python 3.12 con:
#
#   pip install --no-deps -r infra/voz-local/requirements-cuda.txt
#
# Por qué --no-deps y por qué es obligatorio: kokoro-onnx 0.6.1 declara onnxruntime>=1.20.1 como
# dependencia dura (la GPU solo existe como extra "gpu"). Un "pip install kokoro-onnx" traería el
# paquete CPU "onnxruntime", y ese paquete y "onnxruntime-gpu" comparten el módulo "onnxruntime". El
# CPU taparía al GPU y ONNX Runtime caería a CPU sin avisar. Este archivo es un conjunto cerrado: lista
# cada dependencia a mano y no incluye "onnxruntime". Con --no-deps pip no resuelve nada más.
#
# Comprobación tras instalar (las dos deben cumplirse):
#   python -c "import importlib.metadata as m; m.version('onnxruntime')"   # debe lanzar PackageNotFoundError
#   python -c "import onnxruntime as o; print(o.get_available_providers())" # debe incluir CUDAExecutionProvider
# "pip check" se queja de una sola cosa, y es esperada: kokoro-onnx pide onnxruntime y aquí lo
# aporta onnxruntime-gpu. No hay que "arreglarla" instalando onnxruntime.
#
# Librerías de NVIDIA: onnxruntime-gpu 1.31.0 está compilado con CUDA 13.0 y cuDNN 9 (metadatos de
# PyPI: extras "cuda" y "cudnn", y la documentación del CUDA EP desde la 1.27). Los extras traen
# nvidia-cuda-runtime, nvidia-cuda-nvrtc, nvidia-cufft, nvidia-curand y nvidia-cudnn-cu13. cuBLAS y
# nvJitLink llegan como dependencias transitivas de esos wheels y se fijan aquí porque --no-deps no
# las resolvería. Versiones tomadas de un "pip install onnxruntime-gpu[cuda,cudnn]==1.31.0" en un
# venv limpio. CUDA 13.0 exige un driver con soporte de CUDA 13.0 o posterior: se comprueba con
# "nvidia-smi" (campo CUDA Version).
#
# Los pesos fp32 y fp16 se descargan con VERA_VOZ_DESCARGAR_GPU=1 python infra/voz-local/descargar.py.
