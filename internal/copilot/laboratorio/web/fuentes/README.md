# Fuentes locales de Vera

Subconjuntos latinos WOFF2 de las familias utilizadas en la landing de Vera:
Plus Jakarta Sans (400–800), Playfair Display (700) y JetBrains Mono (500–600).
Incluyen las letras acentuadas del español. Se sirven desde el mismo laboratorio;
el navegador no consulta Google Fonts ni otros servidores.

Origen: hojas oficiales de `fonts.googleapis.com`, archivos de `fonts.gstatic.com`.
Las licencias OFL originales se conservan junto a los archivos. No se modificaron
las fuentes ni se utilizaron nombres de familias distintos.

- [Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans)
- [Playfair Display](https://github.com/google/fonts/tree/main/ofl/playfairdisplay)
- [JetBrains Mono](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono)
